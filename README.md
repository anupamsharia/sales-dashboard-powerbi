# 📊 Sales Dashboard (Power BI)

## 🚀 Project Overview

This project is a **Business Sales Dashboard** created using Power BI.
It helps visualize sales performance, trends, and key business insights.

---

## 📁 File Included

* `Business Sales Dashboard 01.pbix`

---

## 🛠️ Tools Used

* Power BI
* Data Visualization

---

## 📊 Features

* Sales overview
* Monthly trends
* Profit analysis
* Category-wise performance

---

## ▶️ How to Use (Beginner Friendly)

### Step 1: Install Power BI

Download from:
https://powerbi.microsoft.com/

### Step 2: Open File

* Open Power BI Desktop
* Click **File → Open**
* Select `Business Sales Dashboard 01.pbix`

### Step 3: Explore Dashboard

* Use filters
* Click charts to interact
* Analyze trends
